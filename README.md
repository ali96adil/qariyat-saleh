# Qariyat Saleh — Digital Performance Page

Mobile-first bilingual (Arabic / English) digital page for the theatre performance **قرية صالح**.

## Permanent public URL

After GitHub Pages is enabled from the `main` branch, the public URL is:

**https://ali96adil.github.io/qariyat-saleh/**

Keep the repository name `qariyat-saleh` unchanged so the printed QR code can keep pointing to the same URL while the page content evolves.

## Enable GitHub Pages once

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Save.

Future commits to `main` will update the same public URL.

## Festival logo

Upload the final festival logo as:

`assets/festival-logo.png`

The page automatically displays a placeholder until that file is added.

## Current experience

- Arabic is the default presentation language.
- Arabic / English switcher.
- Mobile-first responsive layout.
- Sequential card-by-card intro.
- Full creative-team cards after the intro.
- Cold theatrical visual language inspired by the poster direction.
- Reduced-motion accessibility support.
- No external libraries or hosted fonts, so the page is lightweight and durable.

## Editing

The content lives mainly in:
- `index.html` — page structure
- `script.js` — Arabic/English copy and intro sequence
- `styles.css` — visual design and responsive layout
